What is JavaScript?

JavaScript is a programming language used to make websites interactive.

What is the DOM?

The DOM allows JavaScript to access and change HTML elements on a webpage.

What is an Event Listener?

An Event Listener waits for a user action such as a click, key press, or mouse movement.

What is Event Bubbling?

Event Bubbling is when an event starts on the target element and then moves up through its parent elements.

What is a Function?

A function is a reusable block of code that performs a specific task.
